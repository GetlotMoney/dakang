# ArtHeaderBar - 顶部栏组件

系统顶部导航栏组件，提供全局操作入口。

## 基本信息

- **组件名称**: ArtHeaderBar
- **组件路径**: `@/components/core/layouts/art-header-bar/index.vue`

## 功能特性

1. **功能按钮** - 菜单按钮、刷新按钮、全屏按钮等
2. **全局搜索** - 快速搜索功能
3. **通知中心** - 消息通知入口
4. **用户菜单** - 用户信息和操作菜单
5. **主题切换** - 亮色/暗色主题切换

## 基本用法

```vue
<template>
  <ArtHeaderBar />
</template>

<script setup lang="ts">
  import ArtHeaderBar from '@/components/core/layouts/art-header-bar/index.vue'
</script>
```

## 典型应用场景

- 系统全局顶部导航
- 页面级顶部操作栏
