更新日期：2026-07-24

## 状态说明

| 状态 | 定义 |
|---|---|
| Mock | 使用固定或内存数据，主要用于页面开发 |
| 混合 | 同一模块同时包含真实接口和 Mock 功能 |
| 已接入 | 页面已连接真实后端和数据库 |
| 内部链路完成 | 在受控环境完成接口、状态机、数据库和跨端验证 |
| 待开工 | 尚未进入完整业务链实施 |
