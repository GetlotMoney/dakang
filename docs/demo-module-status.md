# 模块实施状态

更新日期：2026-08-13

本文件只回答两个问题：**每个模块/业务链现在是什么状态**、**还缺什么**。它不是变更史——
「做了什么、为什么这么设计、踩过哪些坑」属于代码注释、迁移脚本头注释与测试类 javadoc
（在那里不会与实现漂移），本文件只留指针。需求覆盖与业务链状态以
`requirements/demo-business-chain-matrix.md` 为准，产品决策以 `requirements/decisions.md` 为准。

## 状态说明

| 状态 | 定义 |
|---|---|
| 混合 | 同一模块部分能力已接真、部分仍为只读或待建 |
| 已接入 | 页面已连接真实后端和数据库 |
| 内部链路完成 | 在受控环境完成接口、状态机、数据库和跨端验证 |
| 待开工 | 尚未进入完整业务链实施 |
