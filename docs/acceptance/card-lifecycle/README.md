覆盖场景：

1. 首次购卡、发卡与原子入账（付费新卡永久，`EXPIRE_TIME=NULL`）。
2. 已有卡充值：原卡加权益不建二卡，永久有效期保持 NULL。
3. 待支付订单恢复支付。
4. 创单、支付和超时关单幂等。
5. 冻结后的可恢复重试与归属变化后的人工处理。
6. 水卡范围外预检和强提交拒绝。
7. 实际出水量结算与不足退差。
8. 水卡冻结、解冻和资格恢复。
9. 成员授权、单日限额和撤销。
10. 活动赠卡不可充值：`canRecharge=false` 且创单被拒、零写入（D-213）。

结果仅证明 Pay-Sim、设备模拟器和独立数据库环境中的内部技术闭环，不代表正式微信支付或物理设备已经验收。详细订单号、流水、时间和断言以各批次 `result.json` 为准。
